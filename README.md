## FAQ

**DMIT 有没有长期有效的优惠码？**

没有固定的长期优惠码。DMIT 的折扣主要体现在年付价格上，偶尔有节日促销。与其等优惠码，直接选年付套餐更实际。

**香港套餐和洛杉矶套餐，大陆用户选哪个？**

延迟优先选香港，预算优先选洛杉矶。香港 Pro 系列延迟通常在 30ms 以内，洛杉矶 CN2 GIA 大概在 150-180ms 左右。如果你对延迟不敏感，洛杉矶 T1 系列性价比更高。

**DMIT 的流量是双向计算还是单向？**

DMIT 大部分套餐是双向流量计算（上传+下载都算），部分套餐标注了单向。购买前建议在套餐详情页确认，避免流量超出预期。

**套餐可以随时升级吗？**

可以。DMIT 支持套餐升级，差价按剩余时间折算。如果你不确定自己的需求，可以先买低配，用一段时间再升级。

**支付方式支持哪些？**

DMIT 支持 PayPal、信用卡、加密货币等多种支付方式，对国内用户来说支付门槛不高。

**服务器在哪里管理，操作复杂吗？**

DMIT 有自己的控制面板，支持重装系统、重启、查看流量等基本操作。对有一定 Linux 基础的用户来说上手不难，完全新手的话需要花点时间熟悉。
